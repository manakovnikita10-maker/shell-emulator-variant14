# Конфигурационное управление — вариант 14

## Этап 4. Основные команды

Четвёртый этап подключает команды оболочки к виртуальной файловой системе.

### Реализованные команды

- `ls [PATH]` — содержимое каталога или имя файла;
- `cd PATH` — смена текущего каталога;
- `tac FILE` — строки файла в обратном порядке;
- `uniq FILE` — удаление соседних повторяющихся строк;
- `exit` — завершение программы.

Пути разрешаются относительно текущего каталога, а содержимое файлов читается
из VFS в оперативной памяти.

### Стартовые сценарии

`tests/stage4.txt` проверяет успешные режимы команд текущего и предыдущих
этапов, включая `exit`. `tests/stage4_error.txt` отдельно проверяет ошибку и
остановку сценария при первой ошибке.

### Подготовка и запуск

```bash
python3 tests/make_vfs.py
./run.sh --vfs tmp/nested.zip --script tests/stage4.txt
./run.sh --vfs tmp/nested.zip --script tests/stage4_error.txt
```

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
