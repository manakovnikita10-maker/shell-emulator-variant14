# Конфигурационное управление — вариант 14

## Этап 1. REPL

На этом коммите реализован первый этап практической работы: минимальный
графический эмулятор UNIX-подобной командной оболочки.

### Что реализовано

- GUI на `tkinter`;
- заголовок `Эмулятор - [username@hostname]` из реальных данных ОС;
- приглашение вида `username@hostname:~$`;
- разбор команд через `shlex`, включая аргументы в кавычках;
- обработка неизвестных команд и неверных аргументов;
- команды-заглушки `ls` и `cd`;
- команда `exit`.

### Структура

```text
src/
  main.py
tests/
  test_stage1.py
.gitignore
README.md
run.sh
```

### Запуск

```bash
./run.sh
```

Для демонстрации можно последовательно ввести:

```text
ls
cd test
cd "my folder"
unknown
exit test
exit
```

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
