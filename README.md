# Конфигурационное управление — вариант 14

## Этап 4. Основные команды

На этом коммите VFS уже используется настоящими командами оболочки.

### Что добавлено на этапе 4

- отдельный класс `Shell`;
- команда `ls`;
- команда `cd`;
- команда `tac`;
- команда `uniq`;
- отображение текущего каталога в приглашении;
- обработка ошибок файловых команд;
- стартовый сценарий `tests/stage4.txt`.

Команды работают только с VFS в оперативной памяти. Файлы реальной ОС не
изменяются.

### Подготовка VFS

```bash
python3 tests/make_vfs.py
```

### Запуск

```bash
./run.sh --vfs tmp/nested.zip
```

Автоматическая демонстрация:

```bash
./run.sh --vfs tmp/nested.zip --script tests/stage4.txt
```

### Команды

```text
ls [PATH]
cd PATH
tac FILE
uniq FILE
exit
```

`uniq` удаляет только соседние одинаковые строки, как одноимённая
UNIX-команда.

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
