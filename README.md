# Конфигурационное управление — вариант 14

## Этап 3. Виртуальная файловая система

Третий этап сохраняет этапы 1-2 и добавляет ZIP-VFS, полностью загружаемую в
оперативную память.

### Добавлено

- источник VFS — ZIP-архив;
- ZIP читается напрямую и не распаковывается на диск;
- содержимое файлов хранится в памяти в `base64`;
- автоматически восстанавливается структура каталогов;
- `tests/make_vfs.py` создаёт минимальную VFS, VFS с несколькими файлами и VFS
  с вложенностью не менее трёх уровней;
- `.sh`-сценарии запускают эмулятор на разных VFS;
- `stage3.txt` проверяет команды предыдущих этапов и `exit`;
- `stage3_error.txt` отдельно проверяет остановку при первой ошибке.

Команды `ls` и `cd` на этом этапе ещё являются заглушками. Реальная работа с
VFS через команды появится на этапе 4.

### Подготовка VFS

```bash
python3 tests/make_vfs.py
```

### Запуск

```bash
./run.sh --vfs tmp/minimal.zip
./run.sh --vfs tmp/files.zip
./run.sh --vfs tmp/nested.zip --script tests/stage3.txt
./run.sh --vfs tmp/nested.zip --script tests/stage3_error.txt
```

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
