# Конфигурационное управление — вариант 14

## Этап 2. Конфигурация

Этот коммит содержит первый этап и добавляет настройку эмулятора через
параметры командной строки.

### Что добавлено на этапе 2

- параметр `--vfs` — путь к VFS;
- параметр `--script` — путь к стартовому скрипту;
- вывод обоих параметров при запуске;
- выполнение команд из стартового `.txt`-файла;
- остановка стартового скрипта при первой ошибке;
- системные `.sh`-скрипты для проверки разных вариантов запуска.

Папки `scripts` нет: все небольшие сценарии лежат прямо в `tests`, чтобы
структура проекта была проще.

### Структура

```text
src/
  main.py
tests/
  stage2.txt
  stage2_both.sh
  stage2_script.sh
  stage2_vfs.sh
  test_stage1.py
  test_stage2.py
.gitignore
README.md
run.sh
```

### Запуск

Обычный запуск:

```bash
./run.sh
```

Со стартовым скриптом:

```bash
./run.sh --script tests/stage2.txt
```

С обоими параметрами:

```bash
./run.sh --vfs tmp/example.zip --script tests/stage2.txt
```

На этом этапе путь к VFS только принимается как параметр. Реальная загрузка
ZIP-VFS появится на этапе 3.

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
