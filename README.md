# Конфигурационное управление — вариант 14

## Этап 3. VFS

Этот коммит добавляет виртуальную файловую систему. Источником VFS является
ZIP-архив, который читается напрямую и не распаковывается на диск.

### Что добавлено на этапе 3

- класс `VirtualFileSystem`;
- загрузка ZIP через `zipfile`;
- хранение содержимого файлов в памяти в формате `base64`;
- хранение каталогов в памяти;
- обработка неверного ZIP;
- генератор трёх тестовых VFS;
- системные `.sh`-скрипты для минимальной, обычной и вложенной VFS;
- стартовый сценарий `tests/stage3.txt`.

Отдельной папки `scripts` нет. Все тестовые сценарии находятся прямо в
`tests`.

### Подготовка тестовых VFS

```bash
python3 tests/make_vfs.py
```

Будут созданы временные файлы:

```text
tmp/minimal.zip
tmp/files.zip
tmp/nested.zip
```

Папка `tmp` и ZIP-файлы исключены из Git через `.gitignore`.

### Запуск

```bash
./run.sh --vfs tmp/nested.zip
```

Со стартовым сценарием:

```bash
./run.sh --vfs tmp/nested.zip --script tests/stage3.txt
```

На этом этапе `ls` и `cd` всё ещё являются заглушками. Реальная логика этих
команд появится на этапе 4.

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
