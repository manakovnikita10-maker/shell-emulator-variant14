# Конфигурационное управление — вариант 14

## Этап 2. Конфигурация

Второй этап сохраняет возможности этапа 1 и добавляет параметры запуска и
стартовый сценарий.

### Добавлено

- `--vfs` — путь к виртуальной файловой системе;
- `--script` — путь к стартовому `.txt`-сценарию;
- вывод обоих параметров в окне при запуске;
- выполнение стартового сценария как диалога команд и результатов;
- остановка сценария при первой ошибке;
- три `.sh`-сценария реальной ОС для проверки параметров запуска.

### Структура

```text
src/
  __init__.py
  main.py
tests/
  stage2.txt
  stage2_both.sh
  stage2_script.sh
  stage2_vfs.sh
  test_stage1.py
  test_stage2.py
.gitignore
README.md
run.sh
```

Отдельной папки `scripts` нет: небольшие сценарии находятся прямо в `tests`.

### Запуск

```bash
./run.sh
./run.sh --script tests/stage2.txt
./run.sh --vfs tmp/example.zip
./run.sh --vfs tmp/example.zip --script tests/stage2.txt
```

На этом этапе `--vfs` только принимается как параметр. ZIP будет реально
загружаться на этапе 3.

### Тесты

```bash
python3 -m unittest discover -s tests -v
```
